# Dashboard Streamlit - Atividade 06

Este projeto contém o código completo para a inicialização do dashboard interativo utilizando Streamlit e Plotly.

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o Python instalado em sua máquina.
2. Instale as dependências necessárias executando o comando abaixo no seu terminal:
   ```bash
   pip install streamlit pandas numpy plotly
   ```
3. Navegue até a pasta onde descompactou o arquivo e execute a aplicação com:
   ```bash
   streamlit run app.py
   ```
4. O navegador abrirá automaticamente exibindo o dashboard interativo.
